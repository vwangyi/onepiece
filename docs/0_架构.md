
## turborepo

https://turborepo.dev/
Turborepo是解决Monorepo项目规模变大后，任务执行变慢的问题。
tasks（任务）、dependsOn（依赖关系）和 outputs（缓存输出）。只有正确配置 outputs，
dependsOn：定义任务依赖。最常见的 "dependsOn": ["^build"] 表示“在执行当前包的 build 之前，先执行它所有依赖包的 build”。^ 符号是关键。
outputs：告诉 Turborepo 这个任务会产生哪些文件（如 dist/**、.next/**）。只有在这里正确声明了输出目录，缓存机制才能生效，因为 Turborepo 需要知道要保存和恢复哪些文件。
cache：对于 dev 这类长期运行、不需要缓存的任务，设置为 false。
