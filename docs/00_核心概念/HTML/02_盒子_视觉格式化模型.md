## 视觉格式化模型

- 视觉格式化模型是 块盒 行盒 行级块盒 

## 块盒
```css
.box {
  display: block;
  display: inline;
  display: inline-block;
}
```

块盒特性： 
1. 独占一行
比如 div 

行盒特性：
1. 不会独占一行
比如 span 


行级块盒特性是 既有行盒特性也有块盒特性





## ==========


块盒、行盒、行级块盒，是 CSS 视觉格式化模型里最核心的三种盒子，分别对应 display 属性的三个值：

· 块盒：display: block
· 行盒：display: inline（也可以叫行内盒）
· 行级块盒：display: inline-block

---

一张表看懂区别

特性 块盒 (block) 行盒 (inline) 行级块盒 (inline-block)
是否独占一行 ✅ 是，前后会换行 ❌ 否，与其它行内元素排在同一行 ❌ 否，能与其他内容同行
宽高 (width/height) 可以设置，默认占满父容器宽度 非替换元素(如 span)设置无效，由内容撑开；替换元素(如 img)有效 可以设置
垂直 margin/padding 上下左右都生效，能推开其它盒子 上下 margin/padding 不推开行高（但背景可见），可能重叠；左右正常 上下左右都生效，能推开同行元素和行高
内部可容纳 可以放块盒、行盒、行级块盒 通常只放文字或行内级元素，不能直接放块盒 内部像块盒一样，可以装块级元素

---

展开说说

1. 块盒 (block box)

· 典型元素：<div>、<p>、<h1>~<h6>、<section> 等。
· 独占一整行，就算宽度不够也会把后面的内容挤到下一行。
· 可以完美控制宽、高、内外边距，是页面布局的骨架。
· 不指定宽度时，默认撑满父容器的内容宽度（width: 100%）。

2. 行盒 (inline box)

· 典型元素：<span>、<a>、<strong>、<em> 等。
· 不换行，多个行盒会像文字一样从左到右排列，宽度不够时自动折行。
· 不能直接设宽高（对于非替换元素，如 span，设置 width/height 无效，大小由内容和字体决定）。
· 垂直方向的外边距、内边距比较特殊：
  margin-top/bottom 不推开上下行高（看起来像没生效）；
  padding-top/bottom 会显示背景色，但不影响行框高度，可能会覆盖到上下行文字上。
  只有左右 margin/padding 会正常推开旁边的元素。
· 里面通常只放文字、其它行内元素，不能直接包块级元素。

注意：图片 <img> 虽然是行内替换元素，可以设置宽高，这和 span 不同，但它对外表现仍是行内级别。

3. 行级块盒 (inline-block box)

· 相当于 对外像行盒，对内像块盒 的结合体。
· 可以和文字、其它行内元素排在同一行，但自身内部却可以像块盒一样设置宽高、容纳块级元素。
· 垂直 margin/padding 正常推开上下元素，使行高增加。
· 非常适合做水平排列的导航菜单、卡片网格、按钮组等，既有块盒的尺寸控制能力，又能放在一行内。

---

什么时候用哪个？

· 块盒：大结构、章节、容器，想独占一行就选它。
· 行盒：文本内的强调、链接、小图标混排，不想打断句子流向时使用。
· 行级块盒：需要在一行内放多个“块状”组件（能设宽高、能包内容），比如横向按钮、图片+文字的组合卡片、分页器等等。

## 

视觉格式化模型，简单说就是浏览器把 HTML 元素变成屏幕上一个个可见矩形盒子，并决定它们如何排列、对齐、层叠的一整套规则体系。

你之前问的“块盒、行盒、行级块盒”，其实就是这个模型里最核心的盒子类型。

---

它到底规定了什么？

视觉格式化模型主要处理三件事：

· 生成什么盒子
  每个元素根据 display 属性（block、inline、inline-block、flex、grid 等）生成对应的盒类型。
  比如 <div> 生成块盒，<span> 生成行盒。
· 盒子如何摆放
  由定位方案决定，有三种：
  1. 常规流（正常流）：块盒从上到下一个接一个，行内元素从左到右排满换行。
  2. 浮动（float）：盒子脱离正常流，靠左或靠右，文字会环绕它。
  3. 绝对定位（position: absolute/fixed）：完全脱离正常流，根据包含块定位。
· 盒子之间的相互影响
  比如外边距合并、行盒内行高的计算、以及盒子大小如何受包含块影响等。

---

比喻一下

你可以把视觉格式化模型理解成浏览器的“自动排版引擎”：
你写 HTML 和 CSS 只是给了内容加一些约束，视觉格式化模型就是那套计算规则——在什么位置、画多大的矩形、谁盖在谁上面。

你上次问的块盒、行盒、行级块盒，就是这套规则在常规流中最基础的盒子表现。我们平时说“这个元素独占一行”“那个元素能设宽高”，其实都是在描述视觉格式化模型的行为。
