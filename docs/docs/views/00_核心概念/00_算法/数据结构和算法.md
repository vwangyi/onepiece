## 数组
数组是什么



数组定长，js的数组感觉不是定长的是因为js引擎扩容了，而扩容是消耗性能的，所以尽量预估长度 让长度不变。

比如大多数需要20 你给30就一定够了 那就30 

数组是存储空间是连续的。长度是不变的。 数组好处是通过下标查询性能好。缺点是空间必须连续，容易存在内存碎片导致存不下。


空间碎片（内存碎片）

## 链表
链表是什么 

一个存值 一个存下一个的指针引用 
```ts
const a = { value: 1, next: b };
const b = { value: 2, next: null }
```

链表是 存储空间上不连续。每存放一个值就多开销个引用空间。
好处就是 内存够一定存的下 没有空间碎片问题。
缺点：链表查询某个节点速度慢，每个节点都需要记录下一个节点的引用。



链表特性： 传递链表必须传递链表的根节点。每个节点都认为自己是根节点。

## 链表的反转
- 用递归实现链表的反转
```js
function Node(value) {
    this.value = value;
    this.next = null;
}
const node1 = new Node(1);
const node2 = new Node(2);
const node3 = new Node(3);
const node4 = new Node(4);

node1.next = node2
node2.next = node3
node3.next = node4
node4.next = null



// 每次循环都是改 当前的节点的next指向上个节点 和  把下个节点的next指向当前节点  
function reverse(root) {
    if (root.next.next === null) {
        // root是倒数第二个节点
        // root.next 是倒数第一个节点
        root.next.next = root; // 让 倒数第一个节点的 next 指向倒数第二个节点
        return root.next; // 返回倒数第一个节点（这个节点的next 已经修改正确了）
    } else {
        // 第一次循环 root当前节点为第一个节点 root.next是第二个节点也是下一个节点
        const res = reverse(root.next);
        root.next.next = root; // 把第二个节点的next指向 第一个节点
        root.next = null; // 把第一个节点的next指向null;
        return res;
    }
}

console.log(node1)

// 遍历链表
const newRoot = reverse(node1)
function bianli(root) {
    if (root === null) return;
    console.log(root.value);
    bianli(root.next);
}
bianli(newRoot)
```

## 标准的快速排序
```js 
const arr = [4,1,6,9,3,2,8,7];

function swap(arr, a, b) {
    const tmp = arr[a];
    arr[a] = arr[b];
    arr[b] = tmp;
}

function quickSort2(arr, begin, end) {
    if (begin >= end - 1) return 
    let left = begin;
    let right = end;
    do {
        do left++; while (left < right && arr[left] < arr[begin]);
        do right--; while (right > left && arr[right] > arr[begin]);
        if (left < right) swap(arr, left, right);
    } while (left < right);
    let swapPoint = left === right ? right - 1 : right;
    swap(arr, begin, swapPoint);
    quickSort2(arr, begin, swapPoint)
    quickSort2(arr, swapPoint + 1, end)
}


function quickSort(arr) {
    quickSort2(arr, 0, arr.length);
}

quickSort(arr);

console.log(arr)

```

## 栈
数据结构栈是先进后出
```js
function Stack() {
    this.arr = [];
    this.push = function(v) {
        this.arr.push(v)
    }
    this.pop = function() {
        return this.arr.pop()
    }
}
var stack = new Stack();
stack.push(1);
stack.push(2);
stack.push(3);
console.log(stack.arr)
stack.pop()
console.log(stack.arr)
```

## 队列
队列是先进先出

```js
function Queue() {
    this.arr = [];
    this.push = function(v) {
        this.arr.push(v)
    }
    this.pop = function() {
        return this.arr.shift()
    }
}
var queue = new Queue();
queue.push(1);
queue.push(2);
queue.push(3);
console.log(queue.arr)
queue.pop()
console.log(queue.arr)
```

## 树形结构
只有一个根节点 

树是图的一种

树（有向无环图） 树没有环 有环就变成图了

树是倒着长的 根在顶部 
根节点只有一个
叶子节点：没有其他子节点就是叶子节点。
节点：既不是根节点也不是叶子节点 就叫普通节点

树的度：这颗树最多有叉的节点有多少叉，这颗树的度就是多少
树的深度：树最深有几层 树的深度就是几
