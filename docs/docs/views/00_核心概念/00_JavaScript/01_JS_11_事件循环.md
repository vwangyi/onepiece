

## 事件循环
- 事件循环是 为了解决单线程语言 如何调度任务 实现异步编程的核心机制, 简单来说就是排队。
- 排队规则是：先同步后异步 先微任务后宏任务，执行栈每次执行宏任务前 都会轮询微任务队列 清空微任务队列后再执行一个宏任务。

当前宏任务产生的所有微任务都会全部执行完毕后 再执行下一个宏任务。
常见的微任务
- promise的 then catch finally 
- queueMicrotask 
- new window.MutationObserver(函数); 
常见的宏任务
- 整个script 
- setTimeout
- setInterval
- 交互事件 比如 点击 按键  
- IO操作 读取文件 网络请求回调 

## 事件循环的一轮是指什么   
- 宏任务 -> 同步任务 -> 清空微任务队列 -> 判断渲染 -> 判断空闲 —> 下一轮的一个宏任务
- 也就是说 有多少个宏任务就有多少轮

## 渲染  
渲染是一个阶段  渲染不是任务也不是队列 是一个阶段， 可以说 渲染这个阶段是异步执行的

## rAF 和 rIC
rAF 和 rIC 既不是宏任务，也不是微任务
rAF 是下一次渲染之前调用 ，同一帧所有的requestAnimationFrame 会合并执行。
rIC 是下一次渲染之后有空闲才调用 判断是否有50毫秒的空闲 有空闲就执行rIC  （50ms）    rIC 不建议修改DOM  应用场景 非紧急任务 比如 日志上报 数据预加载
