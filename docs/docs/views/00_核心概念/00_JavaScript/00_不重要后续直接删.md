
## 
标识符是 由 字母 数字 下划线组成 不能数字开头 不能是关键字保留字 区分大小写 是用来命名变量的符号
## Symbol 
Symbol可以用来创建绝对唯一的标识符，不需要关注值本身是什么
Symbol() 不会被遍历 for of forin Object.keys中拿不到symbol()

应用场景，比如 
1. vue模版中的key 可以传Symbol()
2. provide 的key值
3. 常量
```js
export const KEY = Symbol('我是一个key值'); // 参数是描述信息 类似注释
```

## 循环 递归 遍历 迭代的区别  
遍历是 侧重访问数据结构中的每一个元素。只是看一下所有元素。
迭代是 侧重于按顺序从数据结构中一个个主动取出来。按某种顺序取出来所有元素。
循环是 侧重于 重复执行某一段代码。
递归是 函数自己调用自己。没有结束条件就会导致栈溢出
