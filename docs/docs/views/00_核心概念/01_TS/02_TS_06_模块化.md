## 

ts模块化 和 esm 一样   但 import xx from './xxx.ts'不要写.ts后缀  因为编译后没有ts文件

尽量使用 具名导出  少用 默认导出 


```ts
import * as fs from 'fs';  // ts中只能这样导出 不能 import fs from 'fs'; 因为fs是commonjs的 .module.exports = {} 导出的
import { readFileSync } from 'fs' // 或这样 


import fs from 'fs';  // 这样导入 必须加配置 compilerOptions.esModuleInterop: true, 



```


## 在遵循esm的ts中 写commonjs 
```ts 
export = { name: 'hello', sum() {} } // 导出 这种语法 编译后就是 module.export = {}
import xx from './xx' // 导入
import xx = require('./xx') // 导入 

// 不建议ts中使用 commonjs。推荐ts中使用 esm 
```
