
## 
鸭子辩型法：如果它看起来像鸭子，游泳像鸭子，叫声像鸭子，那我就认为它是鸭子。

## 基本类型
- 基本类型需要完全匹配
```ts
let a: string = ''; // 必须赋值的是 字符串
```
## 对象类型
- 对象类型采用 鸭子辩型法
```ts


interface ResponseUser {
  loginId: string
  nickName: string
  gender: '男'｜ '女'
}
const preson = {
  loginId: '1',
  nickName: '1',
  gender: '男'，
  xx: 'xx'
}
// 如果赋值的是一个变量，那就是鸭子辩型法
let user: ResponseUser = preson;  // 成功， 场景 后端接口返回大量的字段 不用每个字段都指定类型
// 如果赋值的是一个字面量对象 那就需要完全匹配
let user1: ResponseUser = {
  loginId: '1',
  nickName: '1',
  gender: '男'，
  xx: 'xx' // 报错 
}
```
