
## 枚举类型
枚举既是类型，也是值：
let s: Status = Status.Done; // 当类型用
console.log(Status.Done);    // 当值用

反向映射

经常用 字面量联合 + const断言 来替代枚举：
```ts
enum Gender {
    male = '男';
    female = '女';
}

let gender: Gender;
gender = Gender.male; // 本质是 男
gender = Gender.female;


// 枚举会出现在 编译结果中 展示形式是 js对象 所以 可以直接 Object.valus(Gender) 拿到一个数组 但这里是any[]
```

## 数字枚举
```ts
// 数字枚举 不赋值 默认从0递增 
enum Gender {
    male = 1;
    female = 2;
}
```
## 枚举

- 定义枚举类型的变量
```ts
// 先定义枚举类
enum Gender { male = 0, female = 1 }; // 默认是 数字枚举 

let g: Gender = Gender.male; // 只能赋值 Gender.male 或 Gender.female 或对应的数字  


enum Member { vip = 'vip', svip = 'svip' }; // 字符串枚举 

let m: Member = Member.vip;
let m1: Member = Member.svip;

 
```
