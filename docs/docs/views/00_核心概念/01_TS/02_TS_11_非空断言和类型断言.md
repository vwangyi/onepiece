## ! 非空断言

```ts
const a = arr[i]; // 如果arr[i] 这个值 ts提示说有可能为undefined 
const a = arr[i]!;  // 值后面加！ 表示非空断言 告诉ts不可能是 undefined  （null同理）
```

## 类型保护函数
- 由于ts不能在运行时态 来判断类型 所以用类型保护函数来模拟
```ts
function hasFireShow(animal: object): animal is IFireShow {
    if ((animal as unknown as IFireShow).singleFire && (animal as unknown as IFireShow).doubleFire) {
        return true;
    }
    return false;
}

// ts不支持 传统的面向对象都支持
if(a instanceof IFireShow) {
    a.singleFire()
    a.doubleFire()
} 
// ts只能用类型保护函数来判断 
if(hasFireShow(a)) {
    a.singleFire()
    a.doubleFire()
} 
```
