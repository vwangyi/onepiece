## 非空断言
非空断言就是在值后面加一个!,告诉ts 不可能是null或undefined，非空就是指不是null或undefined

## 类型断言
类型断言是 在值后面加上 as 一个类型 表示 告诉ts 值就是as后面的类型 

## const断言
const断言是 在值后面加上 as const 告诉ts 值的类型就是值本身字面量

const a = 'a' as const;

## 类型保护

类型保护是通过 typeof instanceof 进行类型判断。

if (typeof a === 'string') a = 'a'

## 类型保护函数
类型保护函数就是 通过 写一个函数返回truefalse 来判断类型。
```ts
function hasFireShow(animal: object): animal is IFireShow {
    if ((animal as unknown as IFireShow).singleFire && (animal as unknown as IFireShow).doubleFire) {
        return true;
    }
    return false;
} 
if(hasFireShow(a)) {
    a.singleFire()
} 
```

## never类型
never类型就是当函数报错时永远不会有返回值，返回值类型就是never

## void类型  
void类型就是 函数没有return 或 return undefined 才使用。如果返回值类型是 undefined 就必须写 return undefined；
