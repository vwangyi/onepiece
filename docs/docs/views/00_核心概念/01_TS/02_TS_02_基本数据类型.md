# 
- ts是一个可选的静态类型系统

## 
对变量进行约束（函数参数和函数返回值 也属于变量）


## 类型推导

- 变量名下有3个点 表示没有类型推导

let phone = '13512341234'
## 
```ts
number：数字
string：字符串
boolean：布尔值
number[]：数字数组
string[]: 字符串数组
Array<number>: 数字数组
Array<string>: 字符串数组
object：对象
null： 空
undefined：空

null和undefined是 所有类型的子类型 可以 let a: string = undefined;

通过 配置 strictNullChecks: true,  null只能赋值给null ，undefined只能赋值给undefined


```

## 联合类型
```ts
let a: number | undefined = 1;

可以通过 typeof 判断类型
```

## void：用于函数返回值 表示没有返回值 虽然默认返回undefined 但还是用 void 

## never：用于函数不可能有返回值 比如 throw 1; 

## 字面量类型：用一个值来约束
const aaa: 1 = 1;
let aaa: 1 | 2 = 1;
let list: [] = [];
const obj: { a: string } = { a: '1' };

不常用 一般用 枚举类型 代替


## tuple元组类型：固定长度的数组 

let axis: [number, string] = [1, 'a']


## any类型 unknow类型
any类型 可以绕过类型约束
