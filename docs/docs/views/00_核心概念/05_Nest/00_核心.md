## @Module装饰器
```ts
@Module({
  imports: [UserModule], // 把写的module放到这里使用 module里面就包含了controller和service 就不用分别引入了
  controllers: [AppController], // 把写的controller放到这里使用
  providers: [AppService], // 把写的service 放到 这里prociders 使用  
})

按照上述注入后 就可以在controller里面使用service了 直接在constructor里面注入就可以了
constroller(private readonly appService: AppService) {}
通过this.appService.方法名() 就可以调用service里面的方法了

从ioc容器里面获取service的实例 直接调用方法就可以了

1. 写的contorller 和 service 要么直接放到 app根模块的 @Module装饰器里面
2. 写的contorller 和 service 要么自己的module里面 然后把自己的module 放到 app根模块的 imports 里面
```

## 三层架构
三层架构是指把整个应用程序分为三层：表示层controller、业务逻辑层service、数据访问层DAO层。 

## controller层 表示层
主要是做 对《拿到的数据》进行过滤校验 对《给出去的数据》进行处理 

## service层 业务层
对业务的增删改查的业务逻辑等等

## dao层数据访问层
对数据库的增删改查 一般用TypeORM 或 sql 

## 实体entity
每张数据库表 对应 一个实体对象。也不一定严格对应，比如 男女对应0和1

只是用来数据传输 controller传递service service传递dao。

业务对象

## MVC
MVC只是用于三层架构中的表示层controller里面的设计模式
三层架构是整个工程的架构模式
MVC和三层架构不是同一个东西，有一定的相似性。
model view controller 指后端的controller
 三层架构的表现层采用MVC设计模式。
 M：Model，业务模型，处理业务
 V：View，视图，界面展示
 C：Controller，控制器，处理请求，调用模型和视图

## MVVM 

前端的MVVM是  
‌Model‌：管理数据处理业务
‌View‌：负责展示界面并接收用户操作。
‌ViewModel‌：作为中间层，把 Model 的数据转换成 View 可用的格式，并响应 View 的变化 。‌‌‌ 不写业务 比如loading  loading一般不是业务




## 业务层封装
三层架构 controller 和 dao 都有库 但业务层没有，因为每个公司不一样，开发者可以根据公司的业务进行封装，学习其他的封装思想就可以用在这里。

可以通过封装 让其他成员直接使用 就可以生成 你写的格式 比如 一键生成 store 

- 但我们作为公司的开发人员 我们在这个公司熟悉业务之后 我们可以针对公司的业务进行合理的封装 
- 我们学习其他的封装思想就可以用在这里

## ioc容器 控制反转容器 （依赖注入） 
ioc容器就是一个维护new Map()容器对象 每次从ioc容器里面拿对象，而不是自己手动去new对象 这样就保证了单例模式。
（手动new对象 这是不标准的做法）

## @Injectable() 装饰器
service里面的 @Injectable() 装饰器 其实就是把这个类实例化为对象注入到ioc容器里面。

## @Controller() 装饰器
controller里面的 @Controller() 装饰器 其实就是把这个类实例化为对象注入到ioc容器里面。

## @Module
@Module({
  provides: [
    {
      provide: 'user_service',  // 
      useClass: UserService,   //
    }
  ]
})
## provides数组
 
1. provide 就是ios容器的map的key值   一般用类名 （key值可以不是字符串）
2. useClass useFactory useValue 就是ios容器的map的value值
2. useClass是一个类
2. useValue是一个值
2. useFactory 是getter函数 这个函数只是初始化调用一次  
3. inject 是给useFactory函数传递参数 

## 从IOC里 取数据
从IOC容器里面获取对象的方式有两种：
1. 构造函数注入
  controller(private readonly appService: AppService) {}
2. 属性注入
  @Inject(AppService)   这个AppService是 provide的值 也就是key值
  private appService: AppService
