
## 枚举类型

```ts
enum Gender {
    male = '男';
    female = '女';
}

let gender: Gender;
gender = Gender.male; // 本质是 男
gender = Gender.female;


// 枚举会出现在 编译结果中 展示形式是 js对象 所以 可以直接 Object.valus(Gender) 拿到一个数组 但这里是any[]
```

## 数字枚举
```ts
// 数字枚举 不赋值 默认从0递增 
enum Gender {
    male = 1;
    female = 2;
}
```
