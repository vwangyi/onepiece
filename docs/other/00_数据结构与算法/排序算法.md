排序算法是计算机科学中用于将数据按特定顺序排列的方法，主要分为比较类和非比较类两大类，包含冒泡、选择、插入、快速、归并、堆排序等经典算法 。根据康奈尔大学计算机系分析，不同算法在时间复杂度和适用场景上有显著差异 。
常见排序算法分类与复杂度对比

1. 比较类排序（通过元素比较决定顺序，时间复杂度下限为 O(n log n)）：
   - O(n²) 级别：冒泡排序、选择排序、插入排序，适合小规模数据。
   - O(n log n) 级别：快速排序、归并排序、堆排序，适合大规模数据。
2. 非比较类排序（不通过比较决定顺序，可突破 O(n log n) 下限）：
   - 计数排序、桶排序、基数排序，时间复杂度可达 O(n)，但要求数据有确定范围或分布特征。
     | 算法名称         | 平均时间复杂度 | 最坏时间复杂度 | 空间复杂度 | 稳定性 |
     | ---------------- | -------------- | -------------- | ---------- | ------ |
     | 冒泡排序         | O(n²)          | O(n²)          | O(1)       | 稳定   |
     | 选择排序         | O(n²)          | O(n²)          | O(1)       | 不稳定 |
     | 插入排序         | O(n²)          | O(n²)          | O(1)       | 稳定   |

3. 快速排序（1960 年由 C. A. R. Hoare 提出）：
   - 核心思想：分治法，选取基准元素将数组划分为小于和大于基准的两部分，递归处理子序列。
   - 优势：内存访问局部性好，实践中常优于其他 O(n log n) 算法。
   - 优化方法：三者值取中选取基准、三路快速排序处理重复值、结合堆排序的内省排序。
4. 归并排序：
   - 核心思想：分治法，将序列递归划分为短序列，再将有序短序列合并为长序列。
   - 特点：稳定排序，性能不受输入数据影响，始终为 O(n log n)，但需要额外内存空间。
5. 冒泡排序与插入排序：
   - 冒泡排序：通过相邻元素比较和交换，使较小元素逐步"浮"到数列顶端，是稳定的排序方法。
   - 插入排序：将待排序元素插入到已排序序列的适当位置，对近乎有序的数据表现优异。
     代码实现与学习建议

6. 代码实现参考：
   - 主流编程语言（Python、C、Java、JavaScript）均有成熟的排序算法实现。
   - 实际开发中建议优先使用语言内置排序函数（如 Python 的 sorted()、Java 的 Arrays.sort()），这些函数通常经过高度优化。
   - 学习时可参考开源代码理解算法思路，再尝试自行实现。
7. 学习建议：
   - 初学者从冒泡、插入排序入手，理解基本比较和交换逻辑。
   - 进阶学习快速、归并排序，掌握分治思想。
   - 特殊场景（如数据范围有限的整数排序）可了解计数、桶排序等非比较类算法。
8. 趣味算法补充：
   - 猴子排序（Bogo Sort）：随机打乱数组直到有序，时间复杂度无上限，仅用于教学演示。
   - 睡眠排序（Sleep Sort）：利用线程睡眠时间排序，属于概念性算法，无实际应用价值。
