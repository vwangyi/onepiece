
## 
根据不同的选择，拉取不同的模版。

## 
#! /usr/bin/env node 
自动查找当前系统的 node 并用 node 执行当前文件。

#! /usr/bin/env python3
自动查找当前系统的python3并用python3执行当前文件。

## 
package.json 中的 bin 字段指定了命令行工具的入口文件。

  "bin": {
    "onepiece-cli": "bin/onepiece-cli.js"
  },

## 
cd 到 onepiece-cli 目录下，执行 npm link，>>> 把当前文件夹作为全局模块安装到当前系统中。
cd 到 onepiece-cli 目录下，执行 npm rm -g onepiece-cli >>> 把当前文件夹从全局模块中移除。
